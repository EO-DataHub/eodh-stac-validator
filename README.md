# EODH STAC Validator

A service to validate STAC objects.

## Development

This package uses the [uv](https://docs.astral.sh/uv/) package manager.

```bash
# initial setup
make setup
```

```bash
# run local dev instance
make run-dev
```

```bash
# run unit tests (watch mode)
make test

# run unit tests (once)
make testonce
```

```bash
# run linting and type checks
make check

# auto-format code
make format
```
